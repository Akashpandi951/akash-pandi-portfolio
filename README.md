# B. Akash Pandi — Personal Portfolio

## Included Files
- `index.html` — Clean, editable portfolio code referencing local files in `assets/`.
- `index_single_file_preview.html` — Self-contained single-file version with embedded images.
- `assets/akash_portrait.jpg` — Original portrait photo (optimized for web).
- `assets/project_preview.jpg` — Featured project visual mockup.
- `.agent/skills/impeccable-ui-ux/SKILL.md` — Ready-to-use UI/UX skill for Google Antigravity.

## Quick Start
1. Unzip this folder and open it in VS Code or Google Antigravity.
2. Open `index.html` with Live Server (or run `python3 -m http.server 8000` and visit `http://localhost:8000`).
3. To publish online, drag and drop this folder into Netlify Drop, Vercel, or push to GitHub Pages.
